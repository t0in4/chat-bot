Answer
Redis lacks RediSearch module** (FT._LIST command missing).** LangChain4j RedisEmbeddingStore requires Redis Stack (Search+JSON modules).

Fix 1: Install Redis Stack (Recommended)
Docker (dev/prod):

text
docker run -d --name redis-stack -p 6379:6379 redis/redis-stack:latest
Local install: Redis Stack Download (includes Search/JSON).

Verify:

text
redis-cli ping  # PONG
redis-cli --raw module list | grep search  # ft  # Should show RediSearch
